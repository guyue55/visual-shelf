# 视觉制作与交付检查规范

更新：2026-11-16。由“阅”主字偏移、印章参照误解、旧包混用这几轮复核沉淀。适用于 Logo、图标、图例、封面及其平台衍生；机器通过与视觉满意分开记录。

## 当前已确认基线

个人作品默认古风、固定 MaShanZheng-Regular、古月章。通用 Logo 正文实际轮廓联合边界居中；古月小章右下落款，圆形额外内收。已确认范本为阅字 v04，不再使用旧 v02/v03 或旧 yue-surface-kit-v01。无字底图 A/C 继续有效。当前可用包为 yue-surface-kit-v02。

## 从各维度检查

| 维度 | 执行方法 | 本轮教训与失败处理 |
| --- | --- | --- |
| 参照与语义 | 写出参照 asset id 并实际打开；准确文案、用途、目标形状明确 | “之前”可能是原右字，不是上一版阅字；不先锁定参照就比较会答非所问 |
| 主字几何 | 对实际正文轮廓求联合边界，核对目标中心，误差≤0.5px | 框内居中≠画布居中；不采用advance或基线代替轮廓；多字整体也检查 |
| 光学观感 | 看实图，比较视觉重心、留白、书法笔画；保留测量与主观判断区别 | 几何通过不自动证明好看；确需光学偏移时明示参数及适用范围 |
| 印章关系 | 分开检查绝对位置、相对正文位置、大小、颜色和落款感 | 主字移动、章坐标没变，整体关系仍变；“章没动”不能代替构图检查 |
| 形状与描边 | 圆形/圆角分别适配；文字与完整章框含描边不越界 | 圆形右下应内收；不能只检查章文字、遗漏边框 |
| 字体与文字 | 固定字体文件及SHA；逐字核对正文/古/月，缺字失败 | 不让模型画字，不静默fallback、变繁体或挤压比例；重排按字数执行 |
| 背景与主体 | 检查去字残影、补绘、alpha碎片、人物/月亮/山体、缩放裁切 | 有碎片的浅色B无字底图不能因Logo B获准而混收；横幅不是拉伸方图 |
| 配色与透明 | 实看纸白、深色、棋盘；检查透明边缘和前背景分层 | SVG字形层不等于完整山水矢量；浅色字不能无底色用作浅色标签栏 |
| 实际尺寸 | 看16/32/48/128等真实像素预览，大图好看不替代小图辨识 | 古月小章在favicon不保证可读；简化无章仅为备选，不自动改默认 |
| 平台格式 | 尺寸/manifest引用/ICO帧/iconset槽位/ICNS头/Android密度和XML/安全圆 | macOS传统ICNS≠现代.icon；PWA图标≠完整安装；不改扩展名冒充转换 |
| 源、权利与复现 | 核对背景/字体/前景/成品哈希、工具与配方，未知模型/许可如实unknown | 原仓库许可不自动是单张图或商标授权；包内相对源应可离线复现 |
| 版本与交付 | 确认绑定准确哈希；只用当前范本和包；核对ZIP解压内容 | 静态校验通过≠用户确认；旧导出禁用并实际清理，不能让AI随手找到旧图继续用；刷新后还要核对实际URL/哈希，避免浏览器缓存旧索引/旧图 |

## 三层验收

1. **自动检查**：render.json 包含main_center_*、seal_bounds/placement、完整形状/安全区结果；visual_qa.py 从实际glyph坐标独立复算正文中心、核对正文与印章、尺寸与封装、配方哈希。不是只相信 passed=true。
2. **实图检查**：AI实际查看来源与产物，至少覆盖大图、缩略图、深浅/透明背景及变更相关构图。记录看过什么、发现什么；未看过不能打勾。背景细节与光学判断没有被自动脚本完整覆盖。
3. **确认与目标环境**：保存用户原话和准确候选哈希；用户已经明确授权按确认规则重导整套时继续执行，不重复索要相同授权。目标设备、安装、缓存、真实域名接入另记实际验证，未完成不冒称完成。

## 完成与清理

先确认新文件已正式收录、包已核对，再清理有问题的素材/草稿/导出及模板引用。删除与替代清单写入 retired/（仅元数据，不留错误图片和ZIP作为可用入口），恢复历史依靠Git。原MacRightClick三张来源及无字底图A/C不属于阅字排版错误，不能误删。新设计另起草稿，不能覆盖已确认文件。

## 缓存也是版本检查的一部分

本轮实际发现服务端已更新但浏览器仍用旧索引。库页面索引fetch采用no-store，本地预览发送Cache-Control:no-store，构建为JS/CSS加内容哈希查询串。消费项目接入新版图标，也应核对真实请求URL、部署base path与缓存更新方式；“点击刷新”或肉眼看起来相似不是拿到新文件的证据。素材卡和详情显示修订号，实际下载仍核对SHA。
