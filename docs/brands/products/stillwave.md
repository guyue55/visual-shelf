# 静澜 Stillwave · 品牌与素材使用档案

- 实体事实与推荐项：[产品登记卡](../../entities/products/stillwave.md)。

- 范围：本次收录的「静」字标识（极简青灰圆形 v02 固定书法体为主推、v01 苹方为废弃历史修订、月夜深蓝圆角为个人作品方向）及后续基于它们的适配。
- 依据：站点页面与 styles/tokens.css 文本核对、用户对候选图的明确确认、固定字体/印章配置文件。尚未获得品牌手册。

## 两套视觉体系（均为设计选择，非站点官方规范）

本库为 stillwave 收录「静」字标识，用 variant 区分，各自规则不可混用：

- **极简青灰（circle-calligraphy，v02，主推）**：贴合站点深色青灰极简语言。配色严格取自 `tokens.css`（底 `#0e1418`、青灰 `#7fa8a0`、字 `#e6edea`）；主字为**项目固定 MaShanZheng-Regular 书法体**真实轮廓（从固定 TTF 加载、SHA `6d2546bb…` 与 provenance 一致、PS 名硬校验、缺字报错；非系统字体、非模型画字）；青灰涟漪同心环呼应站名「澜」与站点 breath-ring；**不带古月章**（产品标识，非个人作品）。渲染器为 `render.swift`（CoreText＋Quartz，字体改为从固定 TTF 加载），不是 `render-logo.sh`。用户 2026-11-17 在书法体/苹方对照实看后明确要求"用书法体的"。
- **极简青灰（circle-minimal，v01，历史修订·已废弃）**：同配色与构图，但主字用系统 PingFang SC，未遵守固定真实字体规范。v02 替代后不再主推、禁止新导出（`packages/advisories.json`），文件仅作历史追溯。
- **月夜深蓝（rounded-moonlit，个人作品方向）**：沿用固定 MaShanZheng-Regular 书法体真实轮廓＋右下固定浅色B古月章蒙版，来自 [个人规范](../../PERSONAL-STYLE.md)。
- 章色规则（深色亮朱红 `#CF6650`、浅色暗朱红 `#A63A30`）只适用于月夜等个人作品版；极简青灰版刻意无章，不适用。
- 两版单字主文案均按真实轮廓几何居中（容差 ≤0.5px，极简版 y 轴另有 breath-ring 光学下移），不通过挪动主字给章让位。
- 新成品先出草稿、实际检查并展示，用户明确满意才收录；两版候选均按此流程于 2026-11-17 确认。

## 站点侧已观察特征（设计上下文，不是新增品牌约束）

- 品牌文字「静澜 Stillwave」，标语「让心，慢下来」；深色低刺激、青灰主色（`#7fa8a0`）、强调隐私与离线。
- 站点视觉以文字和 Unicode 符号为主，没有独立图形 Logo。两版图形标识与站点极简界面是不同表达，不能声称任一版已被站点采纳或与站点统一为一套品牌系统。

## 图标接入现状（2026-11-17 实测，避免误判）

调研方式：直接读取线上 `https://guyue55.github.io/stillwave/` 的 HTML 与 `styles/tokens.css`，并实际浏览器截图核对；非仅凭文本推断。

- 站点 `<html data-brightness="dark">`、`<meta name="color-scheme" content="dark">`，默认深色。
- **favicon 刻意留空**：`<link rel="icon" href="data:,">`。这是有意的空 data URI，不是图标加载失败。
- **全站无任何图片资源**：无 `<img>`、无 `manifest`、无 `apple-touch-icon`、无 `mask-icon`；tokens.css 头部自述"纯 CSS，无外部字体、无图片、无 CDN"。视觉全部由 CSS 与 Unicode 符号绘制。
- 结论：两版「静」字标识目前**均尚未接入站点**，站点也没有既定的图标接入位。它们是按用户"为网站生成图标 + 用静字"的指令制作的**独立可复用素材**；其中极简青灰版是特意为贴合站点语言制作的候选，但仍不是站点现有视觉的一部分，也未获站点官方确认。
- 不擅自改动站点仓库：站点不在本工作区，且用户未授权接入。更关键的是，站点 `<link rel="icon" href="data:,">` 的空 favicon 是为 A6「控制台零 404」验收做的**明确工程决策**（见站点 docs/03-implementation.md 与 04-qa-report.md，有 BR-29 实测背书），且其 QA 静态契约 ST-30 限定发布文件数为 15——接入真实图标属于产品侧改版，需用户明确授权、改站点仓库、同步更新其契约与文档并重跑整套 QA。仅"满意"图标不等于授权改站点。
- 若将来要接入：走极简青灰主推版（v02 固定书法体），按 favicon / PWA / Apple Touch 各自安全区取用场景包成品（不能把圆角主图直接缩放）；在站点侧替换 `data:,` 并保持 `./` 相对路径，重跑站点 QA 确认零 404/零 error（ST-01 不查多余文件、ST-30 不含根目录，通常无需改 `EXPECTED_FILES`；以包内 AGENTS.md §3 为准）；届时再更新实体卡的"已证实使用记录"。当前有效场景包为 `packages/stillwave-web-icon-kit-v02/`，见 [v02 场景包记录](../../creation-runs/2026-11-17-stillwave-web-icon-kit.md)末尾与 [书法体 v02 记录](../../creation-runs/2026-11-17-stillwave-calligraphy-logo.md)。

## 使用约定

1. 介绍本产品的文档或页面默认复用登记卡指定的**主推标识**（极简青灰版）；仅在个人古风作品场景用月夜版。保持比例与透明区域，不拉伸、不改字、不重画章或涟漪。
2. favicon / PWA maskable / Apple Touch / Android adaptive 需按各自安全区重新排版与导出，不把主图直接缩放充当已适配图标；本库已备场景包（见场景包记录），接入站点时优先取用并按站点契约重验。
3. 极小尺寸（16px）下书法体「静」字笔画密、会糊成墨点，旧苹方字版同样如此，换字体解决不了；按用户 2026-11-17 授权，v02 场景包的 16px favicon 已改用清晰的青灰涟漪符号（**仅限该尺寸**的可读性例外，不是全局换字体或系统回退），32/48px 及以上仍用固定书法体。站点用途一律用极简青灰版（无章、涟漪轮廓），不用月夜版；更大尺寸若也想换符号，走场景包 `optional/` 并需明确选择。
4. 修改标识走 logo-adapt 并新建修订；只有用户明确要求改版才走 logo-original。每次先读本档案，不重复询问已确认信息。

## 许可、来源与决策

- 图标为本库按各自配置原创合成：月夜版用 `scripts/render-logo.sh`（Swift/CoreText/CoreGraphics，固定马善政字体＋固定章）；极简青灰 v02 用 `render.swift`（CoreText 从固定 MaShanZheng-Regular.ttf 取真实字形＋Quartz 绘制涟漪，SHA 与 provenance 一致、PS 名硬校验、缺字报错）；均为确定性排版，非图像生成模型画字。v01 曾用系统苹方，已判不合规并废弃。
- 作者、许可、精确色值、可编辑矢量均为 unknown；用户确认满意不等于授予开放许可或完成商标核验。站点色值取自公开 tokens.css 仅用于贴合设计，不表示获得品牌授权。
- 2026-11-17：用户为本网站指定主字「静」，先对圆角月夜候选、后对极简青灰圆形候选均明确回复「满意」；随后指出极简版用系统字体未遵守固定字体规范，本库二次核实确认违规并用固定马善政体重做候选，用户在对照实看后明确要求「用书法体的」，据此收录 v02 为主推、v01 标废弃。单次要求不自动覆盖其他产品规则。
