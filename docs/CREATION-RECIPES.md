# 常用素材制作流程

配合 [AI 创作协议](AI-CREATION.md) 使用。以下为本项目默认工作方式，不是平台官方尺寸、已确认品牌偏好或新增 CLI 功能。本次明确要求与品牌约定优先。

先采用 [个人风格/固定字体/古月章](PERSONAL-STYLE.md)，再按 [平台与形状规范](PLATFORM-PROFILES.md) 选输出配置。背景可以生成或编辑，正文与署名默认由固定字体真实轮廓合成；用户指定不同品牌要求时按对应范围处理。

## logo-original：新原创 Logo

- 输入：实体定位、准确名称（需要字标时）、目标用途、品牌档案及参考。
- 默认：资料足够时先探索 2～3 个不同概念，不为每个概念问一遍完整问卷。没有生成工具时只给概念与执行简报，不称作已出图。
- 固定：用户明确的名称、已有必须保留元素和用途限制。
- 可变：图形概念、构成、组合关系；配色未知时先做可辨识的探索，标为临时假设。
- 终稿路线：选定方向后细化可编辑矢量。按实际需要输出标记/字标/组合、单色与反白版本，不默认一次生成所有组合。
- 验收：24/48px 等常见小尺寸检查（项目验收建议），浅深底、留白、文字与可编辑性。多个尺寸不是自动商标核验。

## logo-adapt：已有 Logo 适配

- 输入：明确的源 asset id、目标背景/布局/尺寸、允许改动项。
- 默认：复用源文件，保持形状与比例。若只要求用于封面，不发起 Logo 重设计。
- 输出：必要的布局/配色/格式变体，记录源 id；可见设计变化按版本规范处理。
- 验收：对照原图，确保没有误改固定形状、文字或颜色。工具不支持准确适配时说明，不以近似重画代替。

## cover-series：系列封面

- 每次输入：实体、准确标题、主题；有副标题、日期、用途变化时再补。
- 从档案复用：Logo id、色值、字体/授权信息、版式参考、禁止项与惯用留白。
- 缺少用途时可先按项目通用 1600×900（16:9）探索；正方形可建议 1200×1200、竖版可建议 1080×1440。这些只是设计预设，实际发布平台要求另行核对。
- 组合流程：背景/主体 → 精确文字排版 → 嵌入真实 Logo → 多尺寸检查。除用户要求外，不把全部文字交给随机生成。
- 无既定版式时可先以约 8% 边距探索，记录假设；不把该比例写成所有品牌的强制规则。
- 验收：缩略图辨识、标题准确、主题差异清楚、系列一致、裁切安全。只修改主题时不重新探索完整品牌。

## diagram-set：成套图标与图例

- 每次输入：概念清单与使用位置；从档案复用线宽、圆角、色彩、背景和文案习惯。
- 默认：先做少量代表性元素确认规则，再扩展成套；已确认规则后不逐个重复询问。
- 输出：每个元素独立文件，同家族/主题标签；共同的画布和视觉比例。
- 验收：同尺寸并排查看、文字语义一致、线宽一致，不能仅检查 SVG 是否可解析。
