## 精确复用

同一源SHA 5f36bc94e402258a98de0fccf577fbf4fb3c464e784f5c926d3e6c39ceb30f9b。新工具按原alpha确定性着色，保留64×114画布及每个透明度像素；实际保存PNG重新解码，逐像素alpha与原源完全相等，所有不透明像素RGB精确等于目标色。实测证据为 [颜色与哈希记录](evidence/2026-11-17-seal-colors.json)。两图已实际查看，并在系列页面确认3份都加载、用途标签清楚。

```sh
# macOS/Swift，无第三方依赖；输出只允许.drafts新目录
swift scripts/export_seal_colors.swift .drafts/<新任务>
```

原蒙版仍是唯一渲染源，resources/seals/guyue-b/provenance.json和render-logo默认配置不变。两份颜色成品用于直接取用，不让渲染器从颜色图再提取，避免透明边缘重复处理。主题按明确light/dark选固定色，不自动随意识别背景换色；复杂背景先提出建议。

当前阅字v06和整套v03无需重做：它们已经使用这两种主题色、相同章源与章比例。原包是确认时的可复现快照，不为两个直接取用色版篡改旧归档；单独需要色版接入包可用packages.py asset --id对应id，网页详情也能直接下载原PNG。

章源是小位图，不冒称纯矢量或原字体工程。字体名和逐图许可仍unknown；不能因为只改颜色就推断已获额外开放许可。查看深浅/棋盘背景时背景切换只影响预览，不改下载文件本身颜色。

页面实际预览见 [印章系列截图](evidence/2026-11-17-seal-color-series.jpg)。本轮按当前发布流程将新增色版同步到线上，发布结果以GitHub Actions和线上索引为准。
