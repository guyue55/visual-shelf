## 当前使用约定

1. 介绍本产品的 README、方案或封面默认复用登记卡指定的主用文件，保持完整比例、透明通道及图形，不拉伸、不镜像、不改“右”字或印章。
2. 现有 1024×1024 q96 PNG 用于应用图标或网页展示。已有圆角和透明区域，不重复加蒙版；不要放大后声称恢复高清或矢量细节。
3. 作为网页/文档标识时可等比缩小，检查目标背景与实际显示尺寸；来源 README 使用 128×128，仅证明该用例，不是所有场景的强制尺寸。
4. 16/32px 等极小尺寸下纹理、人物、印章可能难辨；本轮未做此尺寸的独立验收。需要简化标记时另做有明确变更范围的版本，不能直接把主用图标当作已经验收的 favicon。
5. 制作封面默认走 cover-series：复用主用 PNG，准确标题单独排版。若用户只给主题，可以沿用“月夜深蓝”的现有参考做探索，并明示这是本次设计假设，不写成长期已确认规则。
6. 没有指定封面尺寸时可按项目通用 1600×900 探索，参考 CREATION-RECIPES；具体平台尺寸按真实用途核对。现有图标不直接拉伸成封面背景。
7. 修改 Logo 时走 logo-adapt；只有明确要求改版才走 logo-original。每次先读取本档案，不重复询问已确认的实体、主用文件和来源。
