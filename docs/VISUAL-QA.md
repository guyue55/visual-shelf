更新：2026-11-17。由“阅”主字偏移、印章参照误解、旧包混用这几轮复核沉淀。适用于 Logo、图标、图例、封面及其平台衍生；机器通过与视觉满意分开记录。

## 从各维度检查

| 维度 | 执行方法 | 本轮教训与失败处理 |
| --- | --- | --- |
| 参照与语义 | 写出参照 asset id 并实际打开；准确文案、用途、目标形状明确 | “之前”可能是原右字，不是上一版阅字；不先锁定参照就比较会答非所问 |
| 主字几何 | 对实际正文轮廓求联合边界，核对目标中心，误差≤0.5px | 框内居中≠画布居中；不采用advance或基线代替轮廓；多字整体也检查 |
| 光学观感 | 看实图，比较视觉重心、留白、书法笔画；保留测量与主观判断区别 | 几何通过不自动证明好看；确需光学偏移时明示参数及适用范围 |
| 印章关系 | 分开检查绝对位置、相对正文位置、大小、颜色和落款感 | 主字移动、章坐标没变，整体关系仍变；“章没动”不能代替构图检查 |
| 形状与描边 | 圆形/圆角分别适配；文字与完整章框含描边不越界 | 圆形右下应内收；不能只检查章文字、遗漏边框 |
| 字体与文字 | 固定字体文件及SHA；逐字核对正文/古/月，缺字失败 | 不让模型画字，不静默fallback、变繁体或挤压比例；重排按字数执行 |
| 背景与主体 | 检查去字残影、补绘、alpha碎片、人物/月亮/山体、缩放裁切 | 有碎片的浅色B无字底图不能因Logo B获准而混收；横幅不是拉伸方图 |
| 配色与透明 | 实看纸白、深色、棋盘；检查透明边缘和前背景分层 | SVG字形层不等于完整山水矢量；浅色字不能无底色用作浅色标签栏 |
| 实际尺寸 | 看16/32/48/128等真实像素预览，大图好看不替代小图辨识；尺寸不可辨时走《小尺寸可读性例外》实图对照 | 古月小章在favicon不保证可读；简化无章仅为备选，不自动改默认；例外只限该尺寸且须记录依据，不能借机静默换全局字体/系统字体 |
| 平台格式 | 尺寸/manifest引用/ICO帧/iconset槽位/ICNS头/Android密度和XML/安全圆 | macOS传统ICNS≠现代.icon；PWA图标≠完整安装；不改扩展名冒充转换 |
| 源、权利与复现 | 核对背景/字体/前景/成品哈希、工具与配方，未知模型/许可如实unknown | 原仓库许可不自动是单张图或商标授权；包内相对源应可离线复现 |
| 版本与交付 | 确认绑定准确哈希；只用当前范本和包；核对ZIP解压内容 | 静态校验通过≠用户确认；旧导出禁用并实际清理，不能让AI随手找到旧图继续用；刷新后还要核对实际URL/哈希，避免浏览器缓存旧索引/旧图 |

## 三层验收

1. **自动检查**：render.json 包含main_center_*、seal_bounds/placement、完整形状/安全区结果；visual_qa.py 从实际glyph坐标独立复算正文中心、核对正文与印章、尺寸与封装、配方哈希。不是只相信 passed=true。
2. **实图检查**：AI实际查看来源与产物，至少覆盖大图、缩略图、深浅/透明背景及变更相关构图。记录看过什么、发现什么；未看过不能打勾。背景细节与光学判断没有被自动脚本完整覆盖。
3. **确认与目标环境**：保存用户原话和准确候选哈希；用户已经明确授权按确认规则重导整套时继续执行，不重复索要相同授权。目标设备、安装、缓存、真实域名接入另记实际验证，未完成不冒称完成。

## 工具与记录

```sh

python3 scripts/library.py validate
python3 scripts/packages.py verify packages/yue-surface-kit-v03
```

机器可读清单为 templates/visual/review-checklist.json；归档整套时强制执行visual_qa并要求真实--visual-review-note，写入包内quality-review.json，携带本规范和清单。它只证明所列工程检查通过，不含身份认证或全自动审美判断。明确错误必须修正，不用“用户之前满意”掩盖新发现的问题。

## 完成与清理

先确认新文件已正式收录、包已核对，再清理有问题的素材/草稿/导出及模板引用。删除与替代清单写入 retired/（仅元数据，不留错误图片和ZIP作为可用入口），恢复历史依靠Git。原MacRightClick三张来源及无字底图A/C不属于阅字排版错误，不能误删。新设计另起草稿，不能覆盖已确认文件。

## 缓存也是版本检查的一部分

本轮实际发现服务端已更新但浏览器仍用旧索引。库页面索引fetch采用no-store，本地预览发送Cache-Control:no-store，构建为JS/CSS加内容哈希查询串。消费项目接入新版图标，也应核对真实请求URL、部署base path与缓存更新方式；“点击刷新”或肉眼看起来相似不是拿到新文件的证据。素材卡和详情显示修订号，实际下载仍核对SHA。

## 页面判断也须二次复核

先用当前目录与浏览器确认问题，再用一手规范及实际交互核对取舍；重要结论标明事实、设计选择和未知项。精简时保留取用任务和管理维度，实际检查折叠条件、旧链接恢复、空态、详情、窄屏导航及图片加载；截图不能替代交互。首屏坐标不等于用户耗时，可见性不能只凭元素存在或布局框判断。本轮实例见 [页面精简记录](UX-SIMPLIFICATION.md)。

## 印章字形与章框分开核对

章位相似不代表字形一致。记录准确参照id，分别检查古/月轮廓、收笔、字框比例、边框粗细/纹理与颜色；正文和章的字体源分开说明。仅有PNG时字体名为unknown，不凭相似认定。浅色B为用户2026-11-17指出的优先章样式参照；后续已确认固定独立章并统一为v06，历史比较，见 [复核记录](creation-runs/2026-11-17-seal-reference-and-package-size.md)。

### 独立章候选的检查经验（2026-11-17）

透明提取不能仅以“输出了PNG”判定成功：两次模型提取分别有晕边和笔形漂移，实际看图后弃用。原图小章可先固定来源SHA和笔迹蒙版，保留真实分辨率/算法/颜色与阈值取舍；不臆称已取得原字体或纯矢量。章等比适配，不用拉伸满足旧章框比例。替换示例应从已确认背景/正文重建，在章区域之外逐像素核对无变化，再看实际1024与小尺寸效果。固定蒙版现已获确认，正式渲染/QA与模板已切换为v06/布局3，见 [制作记录](creation-runs/2026-11-17-independent-seal-preview.md)。

## 当前固定章工程门槛（布局3）

固定章必须为shared-guyue-seal-ink-b-v01-png，SHA 5f36bc94e402258a98de0fccf577fbf4fb3c464e784f5c926d3e6c39ceb30f9b。原尺寸64×114、alpha边界[1,1,61,112]、实际轮廓60:111；按profile容纳框等比居中，不再字体重排或另画边框。light只用A63A30，dark只用CF6650，其他配色需要明确需求。

visual_qa独立检查seal_kind/asset/SHA/主题色，复算实际章边界/位置/比例和平台安全圆；核对seal-source.png与seal-layer.png实际哈希/尺寸、foreground.svg唯一内嵌PNG字节及坐标。主字glyph中不得伪造古/月字体轮廓。新版布局缺少fixed-alpha-mask直接失败；新archive要求布局≥3，不能把旧字形章换id收录。SVG含位图章须如实说明，不称纯矢量。

整套与两种模式包核对后，才处理旧素材与出口；清理留retired元数据，禁止旧ID新导出。实际下载也核对SHA，包内脚本要与当前工程一致，并从包内材料复现两款确认PNG为同字节。当前结果见 [v06正式交付](creation-runs/2026-11-17-v06-final-delivery.md)。
