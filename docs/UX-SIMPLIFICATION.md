# 页面精简：依据、取舍与复核

日期：2026-11-17。适用于本轮本地页面；线上版本需另行发布。本页记录设计判断，不把设计系统建议或 AI 自检当成用户研究。

## 问题与证据

用户指出页面花哨、筛选过多。先检查实际页面和目录，再回看设计原则：当前正式目录只有15份素材、6个系列；分类为 Logo 5、图标5、封面3、图例2，状态为可用5、候选2、未标注8。没有用户行为日志，不能据此声称哪个筛选最常用。

旧页面默认同时摆出6个下拉框、5个类型按钮、热门标签、四项统计和大横幅。1280×720、根地址、未滚动时，搜索框顶部646.5px，第一张素材卡顶部897.5px，卡片标题12px。对于“进来找图、看图、取用”的任务，首屏空间优先给工具和素材，是结合用户反馈作出的本项目取舍。

## 一手调研与二次判断

以下来源于2026-11-17查阅；仅采用其明确覆盖的原则。

| 来源 | 直接支持什么 | 再分析后采用什么、保留什么 |
| --- | --- | --- |
| [GOV.UK Details](https://design-system.service.gov.uk/components/details/) | 可折叠只有部分用户需要的内容；不能隐藏多数用户需要的信息，也有人不会点击展开 | 常显搜索与类型；细分筛选及显示设置放“更多选项”。所选条件始终在外面，摘要标出设置项数；带细分参数的旧链接首次进入时展开。搜索/类型优先是当前任务判断，没有使用频率数据背书 |
| [Carbon Content switcher](https://carbondesignsystem.com/components/content-switcher/usage/) | 适合切换同一相关内容的不同视图，每次一个 | 保留“素材 / 系列”两种方式；素材平铺，系列展示合集。目录仍提供项目→系列层级，避免平铺丢失归属入口 |
| [W3C 标题与标签说明](https://www.w3.org/WAI/WCAG22/Understanding/headings-and-labels.html) | 标题、标签需要描述主题或用途 | 用中文任务词替换装饰性英文和含糊按钮；真实作用为说明的入口称“使用说明”。该来源没有规定本项目字号，也不能证明整站符合 WCAG |
| [MDN details](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/details) | 原生 details/summary 提供展开收起，无 open 时关闭 | 使用原生语义，无新增运行依赖；必须实际检查隐藏内容、键盘与窄屏，不能只看 HTML 标签存在 |

反向检查：不能因为“简洁”就删掉组件、功能、平台、状态或透明预览；这些关系是复用管理的实际需求。功能保留，只降低默认展示密度。未来数据量或实际使用反馈改变时，重新评估哪些条件常显，不将本轮布局写成永久通用标准。

## 本轮实现

- 移除大横幅、四项统计、热门标签、装饰英文和倾斜拼图。纸白与淡绿保留个人气质，素材本身的古风、字体、章和文件字节均不修改。
- 默认只常显搜索和类型；“更多选项”分为细分筛选、显示设置。清除筛选只清空筛选维度，保留用户的排序和底色。
- 已选条件可逐项移除；当前条件的零结果选项仍保留。组件、功能、平台、状态计数根据其他条件更新。
- 全部素材平铺，系列切换与左侧目录保留；卡片保留名称、归属/组件、格式/修订以及候选等提醒，完整标签、来源、许可、状态、哈希与取用操作留在详情。
- 手机目录默认隐藏，选中项目/系列后收起并将焦点还给目录按钮；关闭的目录不留在可访问树中。

## 实际验证与限制

同一1280×720、根地址、未滚动复测：搜索框顶部201.59375px，首卡顶部356.59375px，卡片标题15px，默认可见下拉框只有类型。第一排素材已经在首屏。这只是布局改善的量测，不等于用户操作耗时降低或满意度提升。

浏览器实际操作覆盖：Logo+“阅”得到2份v04；打开圆形详情，核对当前路径/修订与下载链接；MacRightClick目录3份，macOS+候选为2份；折叠后条件仍可见，刷新能恢复并展开，移除状态后恢复3份；空搜索结果可清除恢复15份；详情标签“圆形”精确检索为1份；键盘搜索→类型→更多选项→首卡，跳过折叠的选项；使用说明弹窗可打开；系列视图6个合集，透明棋盘设置实际作用于系列预览。390×844时文档宽度390，无横向溢出；目录默认从可访问树隐藏，打开后可进入阅字系列，收起时焦点回到目录按钮。根页15张预览图片均加载成功。

复核中发现：单独用 getClientRects().length 统计可见下拉框会把关闭 details 中的布局框误计为可见。因此补充排除关闭的 details 祖先，并用可访问树与截图交叉确认；不使用第一次计数作为结论。浏览器桥接按标签定位失败时，改用已核对的实际元素 ID；页面可访问树仍显示对应中文标签，不把桥接定位失败直接归因为页面标签错误。
