给收藏添一点新东西

在本地项目运行以下命令，登记文件后重新构建。网页用于浏览，不直接修改仓库。

导入已有素材

python3 scripts/library.py add /路径/logo.svg \
  --id my-logo --name "我的 Logo" --kind logos \
  --tags "品牌,常用" --source unknown --license unknown

创建一张封面

python3 scripts/library.py create \
  --id project-cover --name "项目手记" --kind covers \
  --tags "项目,封面" --author "你的名字"

然后运行 python3 scripts/library.py build，刷新预览。详细流程见仓库 CONTRIBUTING.md。
