# 固定书法字体

Ma Shan Zheng Regular，PostScript 名称 `MaShanZheng-Regular`。源文件来自 Google Fonts，固定提交与 SHA-256 见 provenance.json；上游元数据见 METADATA.pb，字体许可全文见 OFL.txt。

本项目未修改字体。保留许可与版权声明；字体的软件许可不自动成为背景素材或整张成品的许可。本轮字体为可复现排版所选默认方案，用户仍可评价视觉效果；不是恢复原 PNG 中“右”的具体手写字体。

主文案与古月印章使用同一固定字体，以 CoreText 提取真实轮廓后统一缩放，不让图像模型生成文字。印章为竖排书法朱文框，不冒称篆刻字体。换字体须明确变更配置并重新验收，不静默 fallback。
