## 交付取舍

- 默认按用户任务选最小够用范围：单图原文件包→指定场景子包→明确需要全平台或离线创作时才整包。确认的整套仍作为存档保留，不因体积疑问删除已确认材料。
- 当前工具已支持asset和按surface导出，不需要日常总发all。Web子包仍带完整source，属于“可复现开发包”，不能称为最轻运行包。
- 更轻的“只接入”模式可以只带目标入口、必要尺寸、许可/来源、准确确认和校验；“可编辑”模式再带字体/底图/渲染器。当前CLI尚无此模式，不能虚构参数。
- 不盲目删macOS iconset槽、Android密度、PWA安全区变体来减重；它们表达平台用途。后续实现精简模式时需重建清单、相对引用和独立校验，并验证实际接入。
- 当前包没有进入dist/Pages；包大不代表页面会把整包下载到浏览器，也不等于页面运行体积。
