如何制作与收录素材

可以告诉 AI：“给产品 X 做一套月夜古风图标，主字‘阅’，带古月章，包括浏览器标签，先给我看。”

  1. 找到起点读取项目 / 产品、系列、固定字体与平台模板，复用已经确认的偏好。
  2. 制作与预览草稿保存在本地 .drafts；按圆形、封面、浏览器标签等场景分别排版。
  3. 确认后归档你确认满意，才收录准确版本，并补齐归属、系列、组件、功能与标签。

本地命令入口

python3 scripts/studio.py prepare --help
python3 scripts/studio.py review --help
python3 scripts/studio.py accept --help

确认后，按需交付

已确认的图标、图例和封面可以导出原文件接入包，整套作品可以选择 Web、macOS、Android 等场景。包内带来源、确认、使用入口与校验信息；AI 只补问缺失的目标环境，不重复询问同一文件是否满意。

python3 scripts/packages.py list
python3 scripts/packages.py export --help
python3 scripts/packages.py asset --help

这是一座静态素材馆，网页负责浏览和取用。本地脚本负责制作、确认与更新；GitHub Pages 上也不需要运行 Python 服务。草稿不会被构建到站点。
